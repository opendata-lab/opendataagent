# 经验库与用户反馈计划

日期：2026-11-19
设计：[2026-11-19-experience-library-design.md](../design/2026-11-19-experience-library-design.md)
涉及：后端、管理端前端。OntoFoundry 与 Pi 运行时无改动。

## 第一步：用户反馈菜单

1. 迁移：`da_agent_message.feedback_at`；评价变更时写入。
2. `GET /admin/feedback`：筛选与计数，管理员权限。
3. 管理端菜单「用户反馈」。
4. 测试：权限、筛选、计数。

## 第二步：经验库

1. 迁移：`da_agent_experience`。
2. 每日后台作业：选取任务、摘要、调用 `request_model_text`、写入候选；同日不重复。
3. 管理接口与菜单「经验库」：审核（助手级、平台级、忽略）、编辑、停用、新增。
4. 注入：`_build_system_prompt` 附加生效经验（2000 字上限）；全局开关。
5. 测试：任务选取与摘要去除表格数字、预览会话排除、同日不重复、审核状态流转、注入内容与上限、开关关闭时不注入。

## 上线与回退

开关默认关闭；关闭即停止注入，表保留不影响业务。
