# 平台与 Widget 会话统一和续聊实施计划

设计：[平台与 Widget 会话统一和续聊](../design/2026-11-19-unified-conversation-history-design.md)。

1. FastAPI 增加 Widget 显式复用平台认证分支，保留站点检查；在话题存储共用授权谓词，将已验证账号用于话题、消息、任务及文件。增加话题响应来源字段。
2. Vue Chat 使用混合列表及独立的来源筛选，管理员跨用户查阅单独按权限启动。Widget 接入增加同源配置与说明，使用同一会话接口和登录会话。
3. 定向验证站点及账号隔离、匿名行为不变、列表来源切换和只读模式。使用启用登录的本地预览，在两个入口看到同一话题并验证消息和任务状态；没有真实模型配置时如实注明。
4. 前后端一起部署，Widget 接入显式启用，无数据迁移。移除接入配置即可退回原来的宿主身份模式。

管理员权限补充：先收紧运行接口到本人会话，通过管理员只读路由辅助查阅消息和文件，校验为管理员且会话不属于调试预览。前端在管理详情复用文件树和消息附件，并更新反馈、记忆的直达链接。定向测试覆盖请求的角色和所有权、真实文件下载、隔离路径与继续聊天拒绝；使用本地登录预览验证图片和下载。

本地验证：前端 97 项、后端合同与存储单测 57 项通过，另用真实 MySQL 验证两个站点、不同大小写账号 ID 与旧 Widget 记录的归属隔离。平台和 Widget 生产构建通过。Chromium 从 Widget 发起会话，全屏打开平台续聊，再回到 Widget 读取两次回复；同一话题 ID 下两次任务都持久化终态和 SDK 事件。环境为本机 Docker MySQL `127.0.0.1:3326/dataagent_conversation_preview`、Docker Redis `127.0.0.1:6389` DB 14、项目 Python 3.13 和 Pi。模型响应由本地模拟服务给出，未调用真实模型或数据源。

管理员权限验证：147 项后端测试、2 项真实 MySQL 测试、54 项相关前端测试及前端生产构建通过。Chromium 使用管理员登录，从反馈打开另一用户的 Widget 会话，通过消息附件和文件面板分别预览图片，并下载校验了 CSV；平台与 Widget 的他人会话均拒绝运行入口的发送和编辑。管理模式隐藏输入区，管理员自己的会话仍能发送、流式接收并在同一预览环境持久化回复，使用本地模拟模型。

本轮调整：用管理员会话 API 的逐条 `can_continue` 替换前端模式切换。管理员列表保留按助手、来源和用户查看，补后续页加载，选中会话保持独立于列表筛选。统一反馈与记忆 URL。验证点击自己的会话能发送、点击他人的会话没有发送入口且还能访问文件、发起新会话随时可用，以及旧链接可正常打开。
