## Findings and outcomes

| Review finding | Correction | Evidence |
| --- | --- | --- |
| Approved MCP server error left the checkpoint executing | Export the explicit server-error type; persist the known result with `isError: true` and the existing `operation_status=done` contract, then let the model report it. `done` means the result is recorded, not that the business operation succeeded. Transport failures remain unknown and are not replayed. Reserve the first resumed turn before paired tool events, without consuming another model turn. | Pi success/error/disconnect regressions, MySQL reusable-error-result test, real HTTP `MCP_ERROR` scenario |
| Attachments and tokens lost across segments | Save file diffs before leaving parked; merge subsequent diffs by `rel_path` under the existing attachment cap. Sum numeric usage across model turns and persist token totals in the checkpoint across segments. | Real HTTP question/restart/resume verifies both generated files and assistant usage against every persisted usage event |
| Card replies relied on recovery polling; checkpoint conflicts became 500 or silently accepted | Queue first accepted answers/decisions immediately, with MySQL/context work in threads. A response racing the previous segment's lease release is queued when that segment exits. Missing/mismatched checkpoints roll back the answer and return a conflict. | Route idempotency/enqueue contracts, concurrency guard, real MySQL missing/mismatch rollback tests, coordinator fast-answer test, HTTP card flows |
| Large reads copied existing files and could not page compact JSON | Read directly from the source file with bounded line or byte reads. Return the original path and next byte offset, preserving raw JSON exactly. Avoid new files for reads and small errors; large command output stays durable. | Real Docker reconstructs compact UTF-8 JSON through byte pages beyond 16 KiB, checks unchanged results directory, inline errors and full Bash output |
| Mount discovery blocked asyncio; cleanup ran without a sandbox | Resolve configuration in a worker thread; cache successful inspection by CLI/container identity; normalize inspection errors; recognize `/run/.containerenv`. Existing heartbeat frames mark creation intent and successful close. Backend cleanup only handles outstanding intent; exact-name absence checks support optional leading slash, and both cleanup subprocesses have bounded lifetimes. | Cache/error/Podman-marker unit tests, real subprocess lifecycle/usage contracts, real Docker/HTTP/cancel and backend-container tests |
| Superseded interaction loops/event sinks remained | Delete old Python waiter modules, TypeScript interaction helper, unused writer card methods and coordinator callback. Remove tests solely for the deleted paths. | Repository reference checks and full Python/Pi suites |
| Folding regression bypassed afterToolCall and leaked temporary directories | Replace it with a real MCP result folded by afterToolCall, asserting full UI output, bounded model context and saved raw rows. Clean all cell test workspaces and their results siblings after each test. | New MCP folding regression and full Pi suite |
| AGENTS.md described the removed Claude/container engine | Document Pi-only execution, required compile and sandbox-image build with the repository root as Docker build context. | Dockerfile COPY paths and documentation consistency check |
