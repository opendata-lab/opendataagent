# 助手回答完成时间设计

日期：2026-11-27。见[实施计划](../plans/2026-11-27-answer-time-plan.md)。

任务受理时，后端同时写入用户消息和助手占位消息。两个界面读取消息的 `created_at`，所以助手回答显示的是占位时间。任务进入终态时，后端已写入 `da_agent_task.finished_at`。消息反馈会更新消息行的 `updated_at`。

消息查询按 `task_id` 读取任务的 `finished_at`，并通过 `TopicMessage.finished_at` 返回。用户消息和没有完成时间的任务返回 `null`。消息创建时间继续表示行的创建时间。现有数据可直接读取，无需迁移。

主应用和 SDK 在消息操作栏优先显示助手的完成时间。Widget 在自己的消息页脚采用同样的规则。实时流关闭后，两条产品路径从现有任务状态查询获得相同的完成时间。取消响应也携带已落库的完成时间。旧服务或宿主仅提供创建时间时，界面沿用该时间。新建的助手占位可以暂时隐藏时间。
